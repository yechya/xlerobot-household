# 已知边界与未实现能力 (Known Limitations)

本文档主动列出当前实现的边界，避免把 demo 效果误读为通用能力。新增能力前请先更新此文件。

## 硬件与感知

- **仅三路普通 RGB**：不读取深度、点云、激光雷达、力矩或触觉；不得在任务契约中假定这些输入。
- **无全局自主导航保证**：Nav2 backend 默认关闭，需要标定、bringup manifest 与 HIL 报告；`dock_table`
  只解决桌沿局部对准，不是 SLAM 或跨房间路径规划。
- **无通用铰接物体操作**：抽屉/柜门等动作来自专用策略或任务，不构成对任意铰链、把手、滑轨的泛化。
- **无灵巧手**：末端为平行夹爪，不能完成需要多指操作的任务。
- **标定依赖**：相机外参、机械臂零位、桌面高度、串口映射变化都会降低成功率；没有自动在线标定。

## 学习策略

- **权重强过拟合**：现有任务在固定实验室、少量 episode 上微调，跨场景/跨硬件直接使用大概率失败。
  详见 [model-weights.md](model-weights.md)。
- **测试范围**：实机成功率（[results.md](results.md)）来自固定实验台上每项技能 20 次试验，未覆盖其他场景和物体。
- **无通用操作基础模型**：不支持开放词汇的任意抓取/放置；新任务需要采集数据、训练并注册。
- **VLM 仅作证据门禁**：前置/后置检查依赖 VLM 输出，可能存在幻觉或格式错误；系统会 fail-closed，
  但这不是形式化验证，也不保证语义判断正确。

## 任务编排与恢复

- **有界重试**：mission `retry` 最多 3 次，恢复动作只能是 `observe` 或已注册任务；没有开放式重规划。
- **无自动复位**：任务失败后不会自动收回机械臂、清理现场或恢复物体；恢复动作必须显式注册。
- **单任务并发**：同一时间只允许一个真实任务或 mission；没有多机器人协同。
- **无长程自主性**：多技能串联依赖人工审核的 mission 图，不是 LLM 自由生成的计划。

## 安全与合规

- **非功能安全认证**：没有 ISO 13849 / IEC 61508 认证；急停、看门狗和限位是工程保护，不是认证安全功能。
- **物理急停必须独立**：软件 `estop` 不能替代硬件断电回路。
- **VLM 数据流**：相机快照会发送到配置的 HTTP 端点；使用第三方服务时需自行评估隐私、留存与合规。
- **无网络安全认证**：上游 XLeRobot ZMQ 主机未认证，bridge 仅允许 loopback；不要暴露到局域网。

## 可复现性

- **LeRobot 定制已提供补丁，不是完整 fork**：`lerobot_0.3.3_pzy` 的改动整理在
  `integrations/lerobot_jetson/`（上游 `1033680a5`）；π0.5 改动整理在
  `integrations/lerobot_pi05/`（上游 `473f1bd0e`）。均不含权重、数据、engine 或旧历史。
- **XLeRobot 仍为外部依赖**：硬件 3D 打印件、仿真资产与部分 host 驱动需按需克隆上游仓库。
- **权重与数据集未分发**：仓库不包含训练数据、checkpoint、TensorRT engine 或标定缓存。
- **Jetson 版本敏感**：TensorRT engine 与 L4T/CUDA/TensorRT 版本绑定；换版本需要重新导出与编译。
- **无端到端 CI 硬件测试**：CI 只运行主机侧单元/集成测试；没有真实机械臂、相机或 Jetson 的自动化 HIL。
