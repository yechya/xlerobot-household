# XLeRobot 具身家用双臂服务机器人 - 硬件清单与物料指南 (Hardware BOM)

本文档整理了复现与部署 XLeRobot 具身智能双臂移动服务机器人的标准硬件选型、电气连线拓扑与接口约定。

---

## 1. 硬件系统架构概览

```
                     ┌───────────────────────────────────────┐
                     │   边缘计算核心 (NVIDIA Jetson Orin)    │
                     │   Ubuntu 22.04 aarch64 + JetPack 6    │
                     └──────────────────┬────────────────────┘
                                        │
           ┌────────────────────────────┼────────────────────────────┐
```

### 2.3 视觉感知系统
> **设计原则**：系统坚持以**三路低成本通用 RGB 摄像头**作为感知基线，不依赖激光雷达（LiDAR）、深度相机（RGB-D）或力矩传感器伪造输入。

| 摄像头角色 | 安装位置 | 建议视场角 (FOV) | 分辨率与帧率 | 设备映射规则 |
| :--- | :--- | :---: | :---: | :--- |
| **`head_cam`** | 机器人头部云台顶端（俯瞰操作台面） | 90° ~ 120° 广角 | 640x480 @ 30fps | `/dev/video2` |
| **`left_cam`** | 左臂手腕侧方固定位 | 60° ~ 90° 标准 | 640x480 @ 30fps | `/dev/video4` |
| **`right_cam`** | 右臂手腕侧方固定位 | 60° ~ 90° 标准 | 640x480 @ 30fps | `/dev/video0` |

## 3. 串口设备绑定 (Udev Rules 配置)

为了防止系统重启或 USB 插拔后串口设备号变动（如 `/dev/ttyACM0` 与 `/dev/ttyACM1` 颠倒），强烈建议在主控系统上配置 Udev 固定端口别名：

在 `/etc/udev/rules.d/99-xlerobot.rules` 中添加规则：

```udev
# 机械臂左臂舵机驱动板
SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="7523", KERNELS=="1-2.1", SYMLINK+="xlerobot/left_arm", MODE="0666"

# 机械臂右臂舵机驱动板
SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="7523", KERNELS=="1-2.2", SYMLINK+="xlerobot/right_arm", MODE="0666"

# 三全向轮移动底盘控制板
SUBSYSTEM=="tty", ATTRS{idVendor}=="0483", ATTRS{idProduct}=="5740", SYMLINK+="xlerobot/chassis", MODE="0666"
```

重新加载生效：
```bash
sudo udevadm control --reload-rules && sudo udevadm trigger
```

## 4. 安全规范与注意事项

1. **先急停，后通电**：上电自检前确认物理急停处于可触及位置，并在控制软件（`robotd`）启动后先进行 Dry-Run 校验。
2. **电流与地线隔离**：机械臂总线舵机大电流瞬变极易引起 USB 断连，请务必保证舵机供电地线与 Jetson 工控机地线可靠单点共地，严禁通过 USB 接口倒灌大电流。
3. **软看门狗**：底层驱动桥接器（`robot-base-bridge`）设置了 250ms 速度归零和 500ms 硬件失联停车看门狗，任何断连均会触发紧急刹车。
